# Правила для агентов (AshCRM Notify для Windows)

## Назначение

Это отдельное приложение для уведомлений AshCRM. Исходники приложения находятся только в этом репозитории; ядро CRM — в соседнем crm-ashbyte. Не добавлять код приложения в репозиторий CRM.

Перед работой читать docs/APP_SPEC.md и README.md. Требования API CRM описываются в crm-ashbyte/docs/WINDOWS_NOTIFICATIONS_CRM_SPEC.md; протокол ещё согласуется. Документы и общение — на русском.

## Технологии и реализация

- Целевая ОС — Windows 10 и 11; предварительный стек — Go с нативным Windows UI/API. Проверять размер, запуск в трее и поведение окна прототипом, прежде чем фиксировать UI-библиотеки.
- Приложение должно использовать постоянный WebSocket-поток AshCRM для событий, а не частый REST-опрос. При разрыве соединения — переподключение и восстановление пропусков по курсору/непрочитанным событиям.
- Не обходить права CRM на стороне клиента. Пароли не хранить; токены и секреты не коммитить и не выводить в логи.
- Не менять договорённости API самостоятельно: сначала обновить APP_SPEC.md и согласовать соответствующие требования с документацией CRM.

## Версии и Git

- Версия этого приложения хранится только в VERSION. При каждой правке поднимать последнюю цифру (Z) и добавлять запись с той же версией и датой в CHANGELOG.md.
- Работать в ветке cursor/... или claude/...; в main — только через PR.
- Секреты, пользовательские токены и локальные настройки не коммитить.

## Разработка и проверки

- Разрабатывать и проверять локально; подключения к рабочему серверу использовать только с разрешения владельца.
- Не посылать тестовые события сотрудникам/клиентам и не выполнять массовые действия.
- Проверки: `make test`, `make vet` (обе сборки), `make stand-test` против локального стенда CRM. Окна Windows здесь не запускаются — внешний вид проверяет владелец на Windows.
