# Журнал изменений AshCRM Notify для Windows

## [0.0.3] — 2026-10-30

- **Первая рабочая версия** (Go + Win32, без cgo, `dist/AshCRM-Notify.exe` ~8 МБ): вход через браузер (RFC 8252, loopback + PKCE), ключ сессии под DPAPI; одно WebSocket-соединение с CRM — снимок при подключении, `notify.card|clear|sync`, ping, обновление ключа, переподключение с растущей паузой и после сна; карточки — до трёх снизу вверх, ожидание, полоса «ещё N», «Открыть», «Прочитано», «✕»; трей с меню («Не беспокоить», автозапуск, проверка обновлений, выход); два синтезированных звука; ежедневная проверка обновлений по `UPDATE_URL`; один экземпляр на пользователя.
- Тесты: очередь, поток с поддельной CRM (снимок, события до снимка, переподключение, отозванная сессия), вход, звуки, иконки; `make stand-test` — весь клиент против работающей CRM (проходит на стенде 0.0.40). Внешний вид окон на Windows проверяет владелец.
- ТЗ: закрыты открытые вопросы умолчаниями (`docs/APP_SPEC.md` §7).

## [0.0.2] — 2026-10-30

- Уточнена доставка: постоянный WebSocket, без частого опроса, восстановление по курсору и snapshot непрочитанных событий.

## [0.0.1] — 2026-10-30

- Создан отдельный репозиторий приложения, добавлены правила разработки, README и черновик ТЗ.
- Зафиксирована схема получения событий через постоянный WebSocket с восстановлением пропусков; частый опрос API не планируется.
