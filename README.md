# AshCRM Notify для Windows

Отдельное приложение для Windows 10/11: работает в системном трее и показывает уведомления AshCRM собственными карточками.

Состояние: подготовлена структура проекта и черновик требований; реализация ещё не начата. Спецификация: docs/APP_SPEC.md.

## Планируемый принцип связи

Приложение держит одно постоянное WebSocket-соединение с AshCRM и принимает события сразу по мере их появления. Частый опрос API не нужен. При обрыве клиент переподключается и запрашивает непрочитанные/пропущенные события с последнего курсора. В памяти приложения может быть больше трёх ожидающих уведомлений, но одновременно на экране показываются максимум три.

Требования к API ядра ведутся отдельно в соседнем проекте crm-ashbyte, файл docs/WINDOWS_NOTIFICATIONS_CRM_SPEC.md. Точный протокол и вход через браузер ещё согласуются.

## Структура

- AGENTS.md — правила для работы с этим репозиторием.
- docs/APP_SPEC.md — ТЗ приложения.
- cmd/crm-notify-windows/ — точка входа приложения.
