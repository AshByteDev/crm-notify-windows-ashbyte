# AshCRM Notify для Windows

Приложение в области уведомлений Windows 10/11: показывает уведомления AshCRM своими карточками — о том же, что
приходит веб-пушем (личные, группы, беседы с клиентами, очередь, упоминания, задачи, календарь, тревоги). ТЗ —
[`docs/APP_SPEC.md`](docs/APP_SPEC.md), серверная часть — `crm-ashbyte/docs/WINDOWS_NOTIFICATIONS_CRM_SPEC.md`.

## Как работает
* **Вход** — через браузер: «Войти» открывает страницу CRM «Подключить приложение AshCRM для Windows?», код
  возвращается приложению на `127.0.0.1` (RFC 8252 + PKCE). Пароль приложению не передаётся; ключ сессии
  хранится в `%APPDATA%\AshCRM Notify\session.bin`, зашифрованный DPAPI текущего пользователя Windows.
* **Связь** — одно постоянное WebSocket-соединение (`/ws`): при подключении снимок (20 новых карточек), дальше
  события сразу от сервера; без опроса API. Обрыв — переподключение с растущей паузой, после сна компьютера — сразу.
* **Карточки** — одна на чат («ещё N непрочитанных»), до трёх на экране снизу вверх у правого нижнего угла,
  остальные ждут; полоса «Ещё N уведомлений — открыть AshCRM». Кнопки: «Открыть» (браузер на нужном месте),
  «Прочитано» (читает чат в CRM — карточка исчезает на всех устройствах), «✕» (убрать только здесь).
* **Трей** — значок (синий — подключено, серый — нет связи/не выполнен вход, оранжевый — «Не беспокоить», красная
  точка — есть уведомления), меню: «Не беспокоить», «Запускать вместе с Windows», «Проверять обновления», выход.
* Звуки: «клиент» (сообщение клиента, новая беседа) и «прочие»; серия сообщений — один звук.

## Сборка и проверка
Чистый Go без cgo, собирается на любой системе:
```bash
make build SERVER=https://crm.example.ru            # dist/AshCRM-Notify.exe (~8 МБ)
make build SERVER=… UPDATE_URL=https://…/latest.json # с ежедневной проверкой обновлений
make test                                            # логика (очередь, поток, вход, звуки, иконки)
make vet                                             # обе сборки: эта ОС и Windows
make stand-test SERVER=http://localhost:8780 PASSWORD=…  # весь клиент против работающей CRM
make run SERVER=http://localhost:8780                # консольный режим (не Windows): печатает карточки
```
`UPDATE_URL` отдаёт JSON `{"version": "0.0.4", "url": "https://…/AshCRM-Notify.exe", "notes": "…"}`; при новой
версии приложение показывает карточку «Доступна версия …», «Открыть» скачивает файл в браузере.

## Структура
* `cmd/crm-notify-windows` — точка входа (`main_windows.go` — трей, `main_other.go` — консольный режим).
* `internal/app` — всё вместе: сессия, поток, очередь, действия, обновления.
* `internal/queue` — карточки: три на экране, ожидание, «Не беспокоить», отложенные «✕».
* `internal/stream` — WebSocket: снимок, `notify.card|clear|sync`, ping, обновление ключа, переподключение.
* `internal/login` — вход через браузер; `internal/api` — HTTP-вызовы CRM.
* `internal/platform` — настройки, DPAPI, браузер, автозапуск, звук (Windows и заглушки для разработки).
* `internal/winui` — Win32/GDI: трей, меню, окна карточек; `internal/sound` — синтез звуков.
